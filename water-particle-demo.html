Engine Architecture

Engineered for silky-smooth 60 FPS animation with zero external dependencies.

Fluid Wake Dynamics

Calculates cursor velocity vectors to impart realistic directional momentum and bow-waves to nearby leaf icons, swaying and tilting in real-time.

Spring-Damper Physics

Every leaf node is anchored to its grid coordinates with Hooke's elasticity and viscous damping, ensuring organic recoil without abrupt snapping.

Sinusoidal Shockwaves

Continuous mouse movement and clicks trigger expanding circular ripples with accurate wave crest/trough phases, tilting and illuminating leaves.

Simple 3-Line Integration

Drop the standalone component into any HTML5 page in seconds.

index.html Vanilla JS / Zero Dependency 
<!-- 1. Include the canvas element and script -->
<canvas id="bg-canvas" class="water-particles-canvas"></canvas>
<script src="assets/js/water-particles.js"></script>

<!-- 2. Initialize Minimalist Geometric Leaf Icons Grid Background -->
<script>
  const bg = new WaterParticleField({
    canvas: '#bg-canvas',
    gridMode: true,              // Perfectly aligned rows and columns
    gridSpacing: 48,             // Distance between leaf nodes (px)
    shape: 'leaf',               // Minimalist organic leaf icon silhouette
    bubblePalette: [
      { name: 'mintGreen', color: '#98FF98' },   // Fresh Mint Green (#98FF98) → natural freshness
      { name: 'leafGreen', color: '#228B22' },   // Deep Leaf Green (#228B22) → strong organic vibe
      { name: 'aquaBlue', color: '#00CED1' },     // Aqua Blue (#00CED1) → purity & calm
      { name: 'softBeige', color: '#F5F5DC' },    // Soft Beige (#F5F5DC) → eco warmth
      { name: 'whiteGlow', color: 'rgba(255,255,255,0.50)' } // White Glow (#FFFFFF80) → highlight clarity
    ],
    rippleOnMouseMove: true,      // Ripple waves on mouse move
    rippleOnClick: true          // Interactive ripple waves on click
  });
</script>
