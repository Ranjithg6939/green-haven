3. Online Ordering System Architecture

All shopping cart calculations, authentication checks, order placements, and delivery trackers are encapsulated in assets/js/shop.js.

Modular Core in shop.js
  • GH_Auth: Handles login status, current session, credentials verification, logout, navbar state rendering, and route protection.
  • GH_Cart: Manages item additions, quantity modifications, removals, subtotal, tax (8%), delivery fee ($3.99), and coupon discounts.
  • GH_Orders: Stores placed orders, retrieves past records, generates unique Order IDs (GH-XXXXXX), and handles reordering.
  • GH_UI: Shows toast notifications, updates cart badge count across pages, and binds interactive buttons.
Adding Items to Cart from Any Page

Any button with data-add-to-cart attributes will automatically bind to the cart engine:

<button class="btn btn-primary" data-add-to-cart data-id="101" data-name="Truffle Wild Forest Risotto" data-price="26.00" data-image="assets/img/dishes/risotto.jpg" data-category="Mains"> <i class="bi bi-bag-plus"></i> Add to Cart </button>

4. Guest vs Authenticated User Access Rules

Strict access boundaries are enforced across all customer touchpoints:

Guest User Permitted
  • Browse full seasonal menu & filters
  • Search dishes by keyword / ingredients
  • View dish details, recipes & nutrition
  • Add/modify items in cart (stored locally)
  • View cart contents and apply coupons
Guest Gated Actions (Redirected to Login)
  • Proceed to Checkout: Redirected to login.html?redirect=checkout.html
  • Place Order: Requires active session
  • Order History: Redirected to login.html?redirect=orders.html
  • My Account: Redirected to login.html?redirect=my-account.html
Login Notice & Auto-Return

When a guest is redirected to login.html, a prominent alert informs them: �Please login or sign up to continue with your order.� Once authenticated, they are returned seamlessly to their destination.

7. Dark Mode & RTL Compatibility

Every page includes header controls for instant theme toggling and bidirectional layout switching:

  • Theme Engine: Toggles data-bs-theme="dark" or "light" on <html> and persists selection to localStorage.theme.
  • RTL Engine: Toggles dir="rtl" or "ltr" on <html> and dynamically links the Bootstrap RTL stylesheet when enabled.

8. Customization & Connecting Backend APIs

To connect Green Haven to a backend server (Node.js, Laravel, Django, Python FastAPI, or Firebase/Supabase), replace the mock methods in assets/js/shop.js with fetch() or axios calls:

// Example: Connecting placeOrder to your REST API placeOrder: async function(orderData) { try { const response = await fetch('/api/v1/orders', { method: 'POST', headers: { 'Content-Type': 'application/json', 'Authorization': `Bearer ${GH_Auth.getToken()}` }, body: JSON.stringify(orderData) }); return await response.json(); } catch (err) { console.error('Order dispatch error:', err); } }
